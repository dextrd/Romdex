# Romdex guide

Romdex manages your game library: it knows what every file is, and whether it's a good dump. It recognises every file by its hash, against
the No-Intro and Redump DATs you give it, and (in later versions) brings new dumps in, files them, and keeps the library
tidy. It's part of the dextrd family, alongside Melodex for music.

These pages are also in the web app, under **Settings → Help**.

1. [Installing](installing.md): Docker, the folders Romdex needs, and the first start
2. [Getting started](getting-started.md): the setup steps, and where DATs come from
3. [Users and permissions](users-and-permissions.md): accounts, what each permission allows, and API keys
4. [Plugins](plugins.md): the catalogue, intake and connected apps
5. [Configuration](configuration.md): environment variables, ports and paths

Romdex is early: this version sets up accounts, plugins and the API. Systems, matching and intake come next.
